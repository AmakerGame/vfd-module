# Changelog

## [1.0.0] - 2026-09-29

### Added
- Initial VFD Display Module release
- Loadable Kernel Module for Meson-VFD
- sysfs interface for userspace control
- GitHub Actions CI/CD pipeline
- Multi-kernel version support
- Pre-built releases

### Features
- Control VFD display via echo commands
- Support for Linux 5.4, 5.10, 5.15, 6.0, 6.1+
- Automated compilation on multiple kernels
